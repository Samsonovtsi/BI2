# BI2: источник «Карта внедрения по городам техлист»

Источник только для чтения: https://docs.google.com/spreadsheets/d/1lJbEfg6IVThe9vXDYAueJRfztzOvq13oxMw9ttek3M0/edit

Новые страницы: Карта онлайн → Карта по техлисту (#/map/tech-map), Калькулятор АКК → Калькулятор по техлисту (#/calc/tech-calc). Исходные старые расчёты не заменены. Светофор риелторов не менялся.

## Методика

- Наличные: лист «1. 6. Сделки с наличными по город», уникальные техномера объектов по городу и месяцу финансовой даты.
- ЭР: лист «9. 398. Кол-во ЭР по городам», количество по дате регистрации.
- АКК: сумма количеств из листов ДомРФ, Т-Банк, Сбер, ВТБ, Совкомбанк, месяц комиссии банка. Альфа НС и ДомКлик учитываются отдельно.
- Отношение ЭР/АКК к наличным = число ЭР/АКК / число наличных сделок × 100%. Даты и популяции могут отличаться; это НЕ истинная конверсия одной сделки. В отдельных месяцах показатель может превышать 100%.
- Сумма сделок с наличными: в листе «3. 6. Сумма сделок за наличку» используется МЕДИАНА стоимости по городу/месяцу, а не общая сумма. Медианы нельзя суммировать.
- Фактическая комиссия: сумма столбца «Комиссия от банка» реестра «2. 242. Аккредитивы», для распознанных банков АКК. Средняя комиссия = сумма комиссий / число строк операций по дате услуги, не уникальных сделок.
- Доход города = сумма отдельных комиссий × (1 − доля ЦО), только когда известна ставка по банку, городу и месяцу. Неизвестные и отсутствующие периоды не заменять нулём.
- Матрица: по дате, сумме и сроку; фиксированная комиссия либо годовая доля ставки × сумма × дни / 365, при наличии — лимит максимальной КВ. Городская ставка ЦО приоритетнее общей.
- Нулевая процентная ставка с ненулевым лимитом без базовой формулы не определяет выплату. Неоднозначные пересечения интервалов исключаются из автоматического выбора.
- Лучший банк — с максимальной рассчитанной КВ города среди явно подходящих тарифов. Доступность конкретного продукта, договорные исключения и лимиты требуют дополнительной проверки.
- Сравнение: серый диапазон min/max городов с базой не менее 20 сделок, красная линия выбранного города.

## Безопасное подключение к Timeweb

Реестр содержит ФИО клиентов и номера аккредитивов. НЕ открывайте Google-таблицу всем по ссылке, не выкладывайте её в GitHub.

1. В Google Cloud создайте сервисную учётную запись и включите Sheets API.
2. Создайте JSON-ключ, сохраните его в защищённом хранилище. Не отправляйте ключ в чат или Git.
3. Поделитесь исходной Google-таблицей с client_email сервисной учётной записи как Читатель.
4. В Timeweb App Platform добавьте секретную переменную TECH_GOOGLE_SERVICE_ACCOUNT_JSON с полным JSON-ключом, выполните новый деплой.
5. Проверьте GET /api/tech/data — ответ содержит только агрегаты, без строк с ФИО и номерами.
6. Откройте /#/map/tech-map и /#/calc/tech-calc. POST /api/tech/quote рассчитывает тарифы по городу, дате, сумме и сроку.

Частота обновления: 24 часа, при обращении к API; с предыдущим срезом фоновое обновление не блокирует сайт. Ошибка нового источника не удаляет старые аналитические отчёты. Без служебной учётной записи новые показатели остаются недоступными, а не заменяются демонстрационными значениями.

Важно: если источник содержит конфиденциальные агрегаты, защитите весь сайт корпоративной авторизацией. Текущие публичные API BI2 не ограничены ролями.
